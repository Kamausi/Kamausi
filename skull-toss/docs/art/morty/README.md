# Morty: production sheet

Generated by `node tools/angle-sheet.mjs` (after `python3 src/build.py --dev`). The game's own rig draws everything here from the seven SVG layers in [`src/art/skull`](../../../src/art/skull), so it matches the game exactly. Re-run the tool after any change to the layers or the rig.

| File | What it is |
|---|---|
| `front.png` | The neutral front view: transparent, 1000×1000, in the layers' own art space |
| `expressions/<mood>.png` | Each of the rig's 16 moods: transparent, 1000×1200. The x/y match the layers; the extra 200 px below is for the dropped jaw |
| `sheet-expressions.png` | All 16 on one labelled sheet |
| `sheet-landmarks.png` | The front view with its construction: pivot, bounds, cranium and jaw boxes, jaw hinge, nose line, socket ellipses |
| `landmarks.json` | The same landmarks as numbers, in art pixels |

## Landmarks (art pixels, 1000×1000 canvas)
- **Pivot** (500, 494): the rig scales, stretches and rolls about this point. Any new view keeps it.
- **Height**: 63 to 925 with the jaw shut (2.2 skull radii; one radius ≈ 392 px).
- **Jaw hinge** at y 572. The jaw drops up to about 165 px below its rest.
- **Sockets**: the two ellipses in `landmarks.json`. Pupils, lids and brows are drawn inside them in code, not in the SVGs.
- Cranium, jaw, mouth and both teeth rows have their boxes in `landmarks.json`.

## Moods
idle · aim · fear · excited · perfect · confused · deadpan · dizzy · sleep · happy · smug · strain · ouch · gleeful · triumph · ko

## Not done: turned views
The rig only turns Morty in the picture plane (roll). It has no ¼, ½, ¾ or side view, and nothing in the game draws one. Those views are new drawing work for an illustrator. They should keep:
- the pivot;
- the 2.2-radius height;
- the jaw hinge line;
- the cranium-to-jaw proportion;
- the socket and nose landmarks, carried round the head.

Each view should be delivered as the same seven layers on the same 1000×1000 canvas.
